# web_labi# Практична робота №1
Тема: Основи HTML. Структура документа, контент, форми та медіа.

## Що реалізовано
- Головна сторінка з текстом, списками, таблицею та зображенням.
- Сторінка "Контакти" з формою зворотного зв’язку.
- Сторінка "Про мене" з відео та аудіо.
- Структура проекту з папками для сторінок та медіа.

## Як запустити
Відкрити `index.html` у браузері або використати Live Server у VS Code.
