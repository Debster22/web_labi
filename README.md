# Практична робота №2
Тема: Основи CSS. Оформлення багатосторінкового HTML-сайту.

## Що реалізовано
- Підключено зовнішні CSS-файли (style.css, responsive.css).
- Оформлено навігацію, заголовки, списки, таблицю, зображення, форму, відео та аудіо.
- Використано Flexbox для меню та блоків.
- Додано адаптивність через media queries.

## Як запустити
Відкрити index.html у браузері або використати Live Server у VS Code.
